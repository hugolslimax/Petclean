# Petclean
Sistema de Petshop
Projeto simples com Back-end, Front-end e Banco de dados.
## Acesse o projeto
https://petclean.pythonanywhere.com
## Tecnologias
- **Front-end** — HTML, CSS e JavaScript.
- **Back-end** — Python e Flask.
- **Banco de dados** — SQLite.
- **Hospedagem** — PythonAnywhere.
## Requisitos
Python 3.10 ou superior com SQLite 3.35 ou superior.
